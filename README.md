# NewPower Studios 统一开发者网站

用户于 2026-09-15 授权创建公开仓库 pjuneye/pjuneye.github.io，并决定后续所有项目统一使用本站处理开发者网站、产品介绍、支持服务、隐私政策链接和 app-ads.txt 广告授权。

## 统一规则

- 站点：https://pjuneye.github.io/
- 广告授权：https://pjuneye.github.io/app-ads.txt
- 每个项目使用 /<project>/ 目录，提供产品首页、支持和隐私页面。
- Apple 营销网址与 Google Play 开发者网站填写对应产品首页，Training Prompt 为 https://pjuneye.github.io/trainingprompt/。
- app-ads.txt 统一维护在仓库根目录。初始内容复制自 gpshared/app-ads.txt，保留 Google 与 Tappx 现有授权；后续以本仓库为统一发布源，不假设与 gpshared 自动同步。
- 网站首页不得跳转第三方托管商。旧站点保持可访问，逐项目核对并迁移商店网址，不能宣称已有项目自动迁移完成。
- 仅发布产品公开资料和广告授权，不提交凭证、私钥、用户数据或应用业务代码。
- GitHub Pages 使用 main 分支根目录；.nojekyll 保证静态文件直接发布。

Training Prompt 支持与隐私页面沿用 gpshared 已公开版本。新版本界面说明需随产品更新维护。
