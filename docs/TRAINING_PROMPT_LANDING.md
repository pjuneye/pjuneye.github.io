# Training Prompt 落地页展示方案

2026-09-15；站点 /trainingprompt/；统一开发者站点 GitHub Pages。

## 目标与内容顺序

让访问者在首屏理解视觉提示工具的用途，并进入对应商店下载。沿用 App 深绿、暖白、橙色视觉。中英文切换，首次按浏览器语言选择；无需第三方字体或脚本。

1. 品牌导航与首屏：价值主张、实际首页截图、两平台下载入口。
2. 四种素材演示：图片、颜色、文字、Emoji。用户主动选择，不自动闪烁；明确为网页演示。
3. 功能说明：固定／随机间隔、自动／手动切换、自定义内容、大画面展示。
4. 1.7 真实截图：选择场景、准备、训练；标注 iOS 1.7 尚未上线，避免混淆版本可用性。
5. FAQ：功能边界、本地内容、广告与一次性购买、恢复购买。
6. 下载区与支持／隐私／联系入口。

不添加虚构评价、下载量、疗效保证或模拟购买。当前不接入访问统计或点击跟踪。

## 素材来源与维护

WebP 均由 flash-light-app-1.7 真实模拟器截图、现有应用图标和预设动作图压缩生成。原图不变。静态 HTML/CSS/JS，无构建依赖。根 app-ads.txt 不变。

iOS 1.7 上线及 Lifetime Premium 获批后，需更新对应版本提示、FAQ 和原有支持页面中的操作说明。

## 验证

- 浏览器实际检查桌面首屏、截图区、下载区及手机布局。
- 390px、320px 宽度均确认 scrollWidth 等于 viewport width。
- 验证中英文切换、颜色／文字／Emoji 演示和购买 FAQ 展开。
- 无损坏图片；非首屏图片使用懒加载。
- 保留键盘焦点、跳转正文入口、语义标题、按钮状态和减少动态效果支持。

## 自动语言与阿拉伯语（2026-09-15）

默认 HTML 和无法匹配的语言使用英语。自动模式按 navigator.languages 的用户偏好顺序匹配 en、zh、ar（含地区变体）；可手动选择 English／中文／العربية，选择仅保存在本地 localStorage。恢复 Auto 即重新跟随浏览器语言，存储不可用时仍可切换。

阿拉伯语覆盖页面 65 处正文及演示内容，设置 lang=ar、dir=rtl，布局右对齐，实际 App 截图不镜像，英文方向提示 LEFT 保持原内容。支持和隐私链接仍指向原英文页面。

已实际验证：中文浏览器自动选择、阿拉伯语手动选择与刷新记忆、英语恢复 LTR、390px RTL 无横向溢出、阿拉伯语文字演示。未匹配语言回退英语及地区代码匹配通过本地逻辑检查。
